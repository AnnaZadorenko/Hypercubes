# WPI Hypercube Explorer

An interactive website for visualizing hypercubes in three through six dimensions.

The project is based on an original BASIC program created by **Professor P. K. Aravind**. The original program calculates two-dimensional projections of hypercubes and draws their construction step by step. This website recreates those visualizations in a modern web browser using JavaScript and HTML Canvas.

## Visualization

The website includes:

- 3D Cube
- 4D Tesseract
- 5D Isometric Projection
- 5D Tesseract Projection
- 5D Distorted Isometric Projection
- 6D Isometric Projection
- 6D Tesseract Projection

## Features

- Step-by-step hypercube construction
- Multiple 5D and 6D projections
- Play and pause controls
- Adjustable animation speed
- Show or hide vertices
- Show or hide construction paths
- Fullscreen visualization
- Information about each hypercube

## How It Works

A hypercube can be constructed by copying a lower-dimensional cube and connecting the corresponding vertices.

The website follows the construction process of the original BASIC program and displays the resulting higher-dimensional objects as two-dimensional projections.

## Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas

## Running the Project

Run the website through a local web server or host it using GitHub Pages.

Opening `index.html` directly may prevent the description files from loading because they are loaded using JavaScript `fetch()`.
