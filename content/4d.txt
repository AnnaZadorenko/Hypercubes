This animation shows how a 4-cube (or tesseract or hypercube) can be built up through the chain: point --> line --> square --> cube --> tesseract, if each object in this chain is moved along one of the dimensions perpendicular to it. The animation is shown as it appears when projected from the four-dimensional space in which it occurs to the the two-dimensional plane of the computer screen.
The number of vertices of an n-cube is V(n) = 2ⁿ and the number of edges is E(n) = n × 2ⁿ⁻¹. The numbers for a tesseract, for which n = 4, are shown in the boxes below.
