This animation shows how a 3-cube (or ordinary three-dimensional cube) can be built up through the chain: point --> line --> square --> cube, if each object in this chain is moved along one of the dimensions perpendicular to it. The animation is shown as it appears when projected from the three-dimensional space in which it occurs to the the two-dimensional plane of the computer screen.
