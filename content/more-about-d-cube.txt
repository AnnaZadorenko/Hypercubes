# The elements of a d-cube

A d-dimensional cube, or d-cube, has several smaller dimensional cubes inside it as elements. Thus, a 3-cube has points (or vertices), lines (or edges) and squares (or faces) as its elements, these being 0-cubes, 1-cubes and 2-cubes, respectively. For convenience, we will also regard the 3-cube as an element of itself, so that it is the last member of the sequence 0-cube, 1-cube, … just defined. In the same way, a d-cube has k-cubes, for all 0 ≤ k ≤ d, as its elements. This note will show you an easy way to determine the number of k-cubes contained in a d-cube, for each value of k from 0 to d.

The table below shows each d-cube on a separate line, with the number of k-cubes in it shown for each value of k from 0 to d as one moves from left to right along the line. The symbols V, E, F, C, HC, HHC and HHHC at the top stand for vertex, edge, face, cube, hypercube, hyper-hypercube and hyper-hyper-hypercube, respectively, these being the names often used for 0-,1-,2-,3-,4-,5- and 6-cubes when they occur as elements of larger dimensional cubes. The last entry in each row of the table is a 1, for the reason explained earlier. The entries in the first four rows of the table are obvious, but how can we understand the others?

[TABLE]

d | Figure | V | E | F | C | HC | HHC | HHHC
0 | Point | 1 | | | | | |
1 | Line | 2 | 1 | | | | |
2 | Square | 4 | 4 | 1 | | | |
3 | Cube | 8 | 12 | 6 | 1 | | |
4 | HC | 16 | 32 | 24 | 8 | 1 | |
5 | HHC | 32 | 80 | 80 | 40 | 10 | 1 |
6 | HHHC | 64 | 192 | 240 | 160 | 60 | 12 | 1

[/TABLE]

The rule for obtaining any entry of the table is just this: it is twice the entry above it plus the entry to the left of that entry (with 0 taken for any entry that is a blank or outside the table). Thus, the entry 24 in the fifth row is twice 6 plus 12, while 64 in the last row is twice 32 plus 0. The table can be extended downwards beyond the last row as far as one wishes by repeated use of this rule.
*space*
What is the reason for the above rule? It is staring you in the face in all the animations you have seen on this site! To see why, let us first restate the rule as follows:

**The number of k-cubes in a d-cube is twice the number of k-cubes in a (d-1)-cube plus the number of (k-1)-cubes in a (d-1)-cube.**

In each of the animations, you see a d-cube taking shape before your eyes as a (d-1)-cube is dragged along the dimension perpendicular to it and each vertex of the new (d-1)-cube resulting from this displacement is connected to the corresponding vertex of the old one by a line. If you pay close attention to the animation (made easier by slowing it down), you will see that the number of k-cubes in the d-cube is twice the number of k-cubes in the original (d-1)-cube plus the number of (k-1)-cubes in the original (d-1)-cube; the first term in the sum accounts for the fact that each k-cube in the original (d-1)-cube gives rise to another k-cube upon displacement, whereas the second accounts for the fact that each  (k-1)-cube in the original (d-1)-cube gets "stretched" into a k-cube by the displacement along the new dimension. So there you have it!

It is worth mentioning that the numbers in each row of the above table satisfy Euler’s formula for convex polytopes, which states that the sum of the first d numbers in the row for the d-cube, taken with alternating signs (with the first term taken as positive), is 2 if d is odd or 0 if d is even. More specifically,

For a line:      V = 2
For a square:    V − E = 0
For a cube:      V − E + F = 2
For a hypercube: V − E + F − C = 0 etc.
